# Real-Estate-Energy-Intensity-Estimation-Predictive-Modeling
This repository contains a comprehensive data science project focused on estimating energy intensity and building predictive models in the real estate sector. The primary goal is to address energy inefficiency in residential and commercial buildings, which drives up operational costs for developers and property owners alike.

The project is structured into two main phases:
Exploratory Data Analysis (EDA): An in-depth investigation of a rich dataset comprising thousands of observations and dozens of features (primarily weather variables and physical building attributes across the U.S.) to uncover the underlying drivers of energy inefficiency.
Predictive Machine Learning Modeling: Implementation of a supervised machine learning pipeline to accurately forecast key energy consumption metrics (such as Site EUI).

Technologies & Libraries Used:
Python Pandas & NumPy (Data manipulation and analysis), Matplotlib & Seaborn (Data visualization)
